插入排序 (Insertion Sort) 演算法教學

1. 簡介

插入排序是一種簡單且直觀的排序演算法。它的工作原理類似於我們整理撲克牌的方式：將未排序的元素一張一張取出，插入到已排序序列中適當的位置。

與氣泡排序和選擇排序不同，插入排序在資料量小或資料「幾乎已排序」的情況下，效率非常高。

2. 生活案例比喻

  • 整理手上的撲克牌：當你摸牌時，手上的牌是已經排好順序的。當你摸到一張新牌（例如紅心 7），你會從右邊開始比對，把比 7 大的牌（例如 K, Q, 10）往右移，騰出空間，最後把 7 插進去。
  • 圖書館歸還書籍：圖書館員要將一本剛還回來的書放回架上。他會看架上的編號，找到這本書應該在的位置，將後面的書稍微往後推，然後把這本書插進去。

3. 演算法運作步驟

假設要將陣列 arr 由小到大排序 (長度為 $N$)：

  1. 初始狀態：我們假設第一個元素（索引 $0$）已經是「已排序」的狀態。
  2. 第一輪：取出第二個元素（索引 $1$）作為「待插入值 (Key)」。
    • 將 Key 與前面的元素（索引 $0$）比較。
    • 若前面的元素比 Key 大，則將前面的元素往後移一格。
    • 將 Key 放入空出來的位置。
  3. 後續每一輪：取出索引 $i$ 的元素作為 Key。
    • 將 Key 與前面已排序的子陣列（索引 $i-1$ 到 $0$）由後往前逐一比較。
    • 若發現比 Key 大的元素，就將該元素往後移。
    • 直到遇到比 Key 小的元素或比到最前面為止，將 Key 插入該位置。
  4. 終止條件：處理完最後一個元素（索引 $N-1$）後，排序完成。

4. 程式碼實作

Python 實作範例

def insertion_sort(arr):
    n = len(arr)
    
    # 從索引 1 開始處理 (因為索引 0 視為已排序)
    for i in range(1, n):
        key = arr[i]  # 目前要插入的元素
        j = i - 1     # 前一個位置的索引
        
        # 往回比對：只要 j >= 0 且前面的元素比 key 大
        while j >= 0 and arr[j] > key:
            arr[j + 1] = arr[j]  # 將前面的元素往後移
            j -= 1               # 繼續往前找
            
        # 找到適當位置 (因為 j 多減了一次，所以要放在 j+1)
        arr[j + 1] = key
            
    return arr

# 測試區塊
data = [12, 11, 13, 5, 6]
print(f"排序前: {data}")

sorted_data = insertion_sort(data)
print(f"排序後: {sorted_data}")

5. 複雜度分析

  • 時間複雜度 (Time Complexity)：
    • 最佳情況 (Best Case)：$O(N)$。當陣列已經是「已排序」狀態時，每一輪的 Key 只需要比對一次就知道不用移動，效率極高。
    • 最差情況 (Worst Case)：$O(N^2)$。當陣列是「反序」狀態時，每一個 Key 都需要移到最前面，移動次數最多。
    • 平均情況 (Average Case)：$O(N^2)$。
  • 空間複雜度 (Space Complexity)：
    • $O(1)$。屬於原地排序 (In-place Sort)。

6. 特性總結與適用時機

  • 穩定性 (Stability)：穩定。
    • 當遇到相等的元素時，我們不會將它往後移，Key 會被插在該元素的後面，因此相對順序不變。
  • 優點：
    • 適應性 (Adaptive)：對於「部分排序」或「幾乎已排序」的資料，效率接近 $O(N)$，表現優於快速排序。
    • 線上演算法 (Online)：可以一邊接收資料一邊排序。
    • 在資料量極小 (例如 $N < 16$) 時，通常比快速排序 ($O(N \log N)$) 還要快（因為沒有遞迴呼叫的額外開銷）。
  • APCS 考試應用：
    • 第 1、2 題：若題目給定一個已排序陣列，要求插入一個新數字並保持排序，這就是插入排序的其中一步驟。
    • 第 3、4 題：雖然是 $O(N^2)$，但在某些特定測資（幾乎已排序）下可能不會超時，不過一般情況下仍建議使用內建 sort()。
