選擇排序 (Selection Sort) 演算法教學

1. 簡介

選擇排序是一種簡單直觀的排序演算法。它的核心概念是「不斷地從未排序的數列中找出最小（或最大）的元素，將其放到已排序數列的末端」。

與氣泡排序不同的是，選擇排序每一輪只進行一次交換（將找到的最小值換到正確位置），因此交換次數較少，但比較的次數依然很多。

2. 生活案例比喻

  • 體育課排身高：老師看著全班亂七八糟的隊伍，先把全班掃視一遍，找出最矮的同學，請他站到第一個位置。接著，老師忽略已經排好的第一位，從剩下的人裡面再掃視一遍，找出剩下人當中最矮的，請他站到第二個位置。重複這個動作，直到所有人都排好。
  • 整理撲克牌：你手上有 13 張雜亂的牌。你先看過所有牌，找出最小的「梅花 2」，把它抽出來放到最左邊。接著在剩下的 12 張牌中找最小的，放到「梅花 2」的右邊。依此類推。

3. 演算法運作步驟

假設要將陣列 arr 由小到大排序 (長度為 $N$)：

  1. 第一輪：
    • 假設索引 $0$ 的位置是最小值。
    • 從索引 $1$ 到 $N-1$ 掃描整個陣列，尋找比 arr[0] 更小的數。
    • 如果找到更小的數，記錄其索引為 min_index。
    • 掃描結束後，將 arr[0] 與 arr[min_index] 交換。
    • 此時，索引 $0$ 的位置已確定是全陣列最小的數。
  2. 第二輪：
    • 從索引 $1$ 開始，重複上述步驟（在 $1$ 到 $N-1$ 中找最小的）。
    • 找到後，將其與 arr[1] 交換。
  3. 重複執行：第 $i$ 輪從索引 $i$ 開始尋找最小值並交換。
  4. 終止條件：執行到 $N-1$ 輪時，最後一個元素自然是最大的，排序完成。

4. 程式碼實作

Python 實作範例

def selection_sort(arr):
    n = len(arr)
    
    # 只需要跑 n-1 輪，因為最後一個剩下的肯定是最大的
    for i in range(n - 1):
        # 假設目前的 i 是最小值的索引
        min_idx = i
        
        # 從 i+1 開始往後找，看有沒有更小的
        for j in range(i + 1, n):
            if arr[j] < arr[min_idx]:
                min_idx = j  # 更新最小值索引
        
        # 如果找到的最小值索引不是原本的 i，則交換
        if min_idx != i:
            arr[i], arr[min_idx] = arr[min_idx], arr[i]
            
    return arr

# 測試區塊
data = [64, 25, 12, 22, 11]
print(f"排序前: {data}")

sorted_data = selection_sort(data)
print(f"排序後: {sorted_data}")

5. 複雜度分析

  • 時間複雜度 (Time Complexity)：
    • 所有情況 (Best, Worst, Average)：$O(N^2)$。
    • 原因：無論陣列是否已經排序好，選擇排序每一輪都必須「完整掃描」剩餘的陣列來確認誰是最小值。它無法像氣泡排序那樣提早結束。
  • 空間複雜度 (Space Complexity)：
    • $O(1)$。屬於原地排序 (In-place Sort)。

6. 特性總結與適用時機

  • 穩定性 (Stability)：不穩定。
    • 例如陣列 [5, 5, 2]。第一輪會將第一個 5 與 2 交換，變成 [2, 5, 5]。原本在前面的 5 被換到了後面，相對順序改變了。
  • 優點：
    • 實作簡單。
    • 交換次數最少：在所有 $O(N^2)$ 的排序演算法中，選擇排序的資料交換 (Swap) 次數最少（最多 $N-1$ 次）。如果「寫入記憶體」的操作成本很高（例如 Flash Memory），選擇排序可能比氣泡排序好一點。
  • 缺點：
    • 速度慢，永遠是 $O(N^2)$。
  • APCS 考試應用：
    • 第 1、2 題：可能會考追蹤程式碼執行過程（Trace code），問你「執行完第二輪後，陣列長什麼樣子？」。
    • 第 3、4 題：同樣不建議使用。若需排序請直接使用 Python 內建的 sort()。
