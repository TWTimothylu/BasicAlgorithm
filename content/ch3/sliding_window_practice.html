練習題：無重複字元的最長子字串 (Longest Substring Without Repeating Characters)

問題描述

給定一個字串 s，請找出其中不含有重複字元的最長子字串的長度。

輸入範例

s = "abcabcbb"

輸出範例

3

範例解釋

因為無重複字元的最長子字串是 "abc"，所以其長度為 $3$。

補充測資

測資編號 輸入 (s) 預期輸出 說明
1 "bbbbb" 1 最長子字串是 "b"，長度為 $1$。
2 "pwwkew" 3 最長子字串是 "wke"，長度為 $3$。注意 "pwke" 不是子字串，而是子序列。
3 "" 0 空字串長度為 $0$。
實作提示 (Sliding Window + Hash Map)

這題是變長滑動視窗的經典應用：

  1. 定義指標與資料結構：使用 left 指標代表視窗左邊界，並使用字典（Hash Map）記錄每個字元最近一次出現的索引位置。
  2. 右指標遍歷：使用 right 指標遍歷字串。
  3. 更新左指標：如果當前字元 s[right] 已經在字典中，且其索引位置在 left 之後（或等於 left），說明發生了重複。將 left 指標直接跳到該重複字元上次出現位置的下一個索引：left = char_map[s[right]] + 1。
  4. 計算長度：在每一步中，計算當前視窗長度 right - left + 1 並更新最大值。
  5. 更新字典：將當前字元及其索引存入（或更新）字典中。

複雜度分析

  • 時間複雜度：$O(n)$，其中 $n$ 為字串長度。
  • 空間複雜度：$O(\min(m, n))$，$m$ 為字元集的大小（例如 ASCII 或 Unicode 範圍）。
