雙指標 (Two Pointers) 演算法教學

1. 簡介

雙指標（Two Pointers）是一種在陣列或字串中利用兩個變數（指標）協同走訪資料的演算法策略。這兩個指標可以從不同的起始位置出發，以不同的步長或方向移動。

其核心價值在於將原本需要巢狀迴圈（$O(N^2)$）的窮舉搜尋，最佳化為單次走訪（$O(N)$），大幅降低時間複雜度。

常見的雙指標模式有三種：

  1. 相向雙指標 (Opposite Direction)：一個在頭，一個在尾，往中間夾擊（常用於已排序陣列）。
  2. 同向雙指標 (Same Direction)：兩個都在頭，通常一個快一個慢（常與滑動視窗 Sliding Window 結合）。
  3. 快慢指標 (Fast & Slow Pointers)：步長不同，常用於鏈結串列（判斷循環或找中間點）。

2. 生活案例比喻

  • 相向雙指標 - 湊整數結帳：假設你在特賣會，衣服價格已經由低到高排列好。你有 1000 元的折價券，必須買剛好兩件衣服把券用完。你先拿最便宜和最貴的衣服加起來看，如果超過 1000，就把最貴的放回去，換第二貴的；如果不到 1000，就把最便宜的放回去，換第二便宜的。如此夾擊，很快就能找出剛好 1000 元的組合。
  • 快慢指標 - 操場跑步：兩個人在環型操場跑步，A 的速度是 B 的兩倍。如果操場是環型的（有迴圈），跑得快的 A 遲早會從背後追上並超越 B（套圈）。這常用來判斷路線中是否有「死循環」。

3. 演算法運作步驟 (以相向雙指標尋找目標和為例)

假設要在已遞增排序的陣列 arr 中，尋找兩個數字使其總和等於 target：

  1. 設定左指標 left = 0（指向最小值）。
  2. 設定右指標 right = 陣列長度 - 1（指向最大值）。
  3. 當 left < right 時，執行以下判斷：
    • 計算當前總和 current_sum = arr[left] + arr[right]。
    • 若 current_sum == target：找到答案，回傳兩個指標的位置。
    • 若 current_sum < target：代表總和太小，將左指標往右移 (left += 1)，以換取更大的數字。
    • 若 current_sum > target：代表總和太大，將右指標往左移 (right -= 1)，以換取更小的數字。
  4. 若迴圈結束仍未找到，回傳失敗訊息。

4. 程式碼實作

Python 實作範例 (相向雙指標 - Two Sum II)

def two_sum_sorted(arr, target):
    """
    相向雙指標：在已排序陣列中尋找兩數之和等於 target
    """
    left = 0
    right = len(arr) - 1
    
    while left < right:
        current_sum = arr[left] + arr[right]
        
        if current_sum == target:
            return [left, right]  # 找到目標組合的索引
        elif current_sum < target:
            left += 1             # 總和太小，左指標右移
        else:
            right -= 1            # 總和太大，右指標左移
            
    return [-1, -1]  # 未找到

# 測試區塊
# 注意：陣列必須是已排序的
data = [2, 7, 11, 15, 20]
target_value = 18

result = two_sum_sorted(data, target_value)
if result != [-1, -1]:
    print(f"找到目標和，索引為: {result[0]} 和 {result[1]}")
    print(f"數值為: {data[result[0]]} + {data[result[1]]} = {target_value}")
else:
    print("未找到符合的組合")

5. 複雜度分析

  • 時間複雜度 (Time Complexity)：
    • $O(N)$。兩個指標最多共同走過整個陣列一次，沒有任何元素被重複走訪。相較於雙層迴圈的 $O(N^2)$，有極大的效能提升。
  • 空間複雜度 (Space Complexity)：
    • $O(1)$。只需要常數個變數（left, right）來記錄位置，不需要額外配置陣列或記憶體。

6. 特性總結與適用時機

  • 先決條件：若使用相向雙指標尋找數值組合，陣列通常必須先經過排序。
  • 適用題型：
    • 求特定總和/差值的組合。
    • 陣列原地操作（例如移除特定元素、將零移到末端）。
    • 迴文（Palindrome）判斷（從頭尾向中間比對字元）。
  • APCS 考試應用：
    • 雙指標是 APCS 實作題 第 3 題 最常見的核心技巧之一。通常會與「排序」、「貪婪演算法」或「滑動視窗」結合出現，用來將原本會 Time Limit Exceeded (TLE) 的暴力解最佳化。
