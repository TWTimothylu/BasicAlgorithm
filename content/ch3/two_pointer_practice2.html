練習題：長度最小的子陣列 (Minimum Size Subarray Sum)

問題描述

給定一個含有 $n$ 個正整數的陣列 nums 和一個正整數 target。找出該陣列中滿足其和 $\ge target$ 的任意連續子陣列，並回傳其最小長度。如果不存在符合條件的子陣列，回傳 $0$。

輸入範例

target = 7, nums = [2, 3, 1, 2, 4, 3]

輸出範例

2

範例解釋

子陣列 [4, 3] 是該條件下長度最小的連續子陣列（長度為 $2$）。

補充測資

測資編號 輸入 (target, nums) 預期輸出 說明
1 4, [1, 4, 4] 1 元素本身即等於 target。
2 11, [1, 1, 1, 1] 0 總和未達 target，回傳 $0$。
3 11, [1, 2, 3, 4, 5] 3 子陣列 [3, 4, 5] 滿足條件且長度最小。
實作提示 (同向指標 / 滑動視窗思路)

這類題目指標均由左向右移動，但並非固定倍數關係：

  1. 初始化：left = 0，right = 0，當前窗口總和 current_sum = 0，最小長度 min_len = float('inf')。
  2. 擴展窗口：移動 right 指標，將 nums[right] 加入 current_sum。
  3. 收縮窗口：當 current_sum >= target 時，嘗試縮小窗口以尋找更短的可能：
    • 更新 min_len = min(min_len, right - left + 1)。
    • 從 current_sum 中減去 nums[left]。
    • 將 left 指標向右移動一步（left += 1）。
    • 重複步驟 3 直到 current_sum < target。
  4. 繼續遍歷：重複步驟 2，直到 right 到達陣列末尾。
  5. 結果判斷：若 min_len 仍為初始值，代表無解，回傳 $0$；否則回傳 min_len。

複雜度分析

  • 時間複雜度：$O(n)$。雖然有巢狀迴圈，但每個元素最多被 left 和 right 各訪問一次。
  • 空間複雜度：$O(1)$。
