滑動視窗 (Sliding Window) 演算法教學

1. 簡介

滑動視窗（Sliding Window）是同向雙指標（Two Pointers）的一種進階應用策略。它的概念是維護一個在資料（陣列或字串）上移動的「視窗」，透過左右邊界的移動來框出一段連續的區間。

根據問題需求，滑動視窗可以分為兩種：

  1. 固定長度視窗 (Fixed-size Window)：視窗大小不變，整體向右滑動。
  2. 可變長度視窗 (Variable-size Window)：視窗大小會根據條件動態伸縮（右邊界擴張、左邊界收縮）。

其最大優勢在於避免重複計算重疊區間的元素，將時間複雜度從 $O(N^2)$ 降低至 $O(N)$。

2. 生活案例比喻

  • 固定長度視窗 - 計算一週平均氣溫：假設你有 30 天的每日氣溫紀錄，你想找出「連續 7 天」總和最高的區間。你不需要每次都重新加總 7 天的氣溫。當視窗從「第 1~7 天」滑動到「第 2~8 天」時，你只需要將原本的總和「扣掉第 1 天，加上第 8 天」即可。
  • 可變長度視窗 - 吃到飽餐廳拿食物：你拿著一個盤子在夾菜，規定是「總熱量不能超過 1000 大卡」。你一路往下夾（右邊界擴張），當夾到某一道菜發現總熱量爆表時，你就必須從盤子裡「最先夾的菜」開始拿掉（左邊界收縮），直到熱量再次低於 1000 大卡，然後才能繼續往下夾新的菜。

3. 演算法運作步驟 (以可變長度視窗為例)

假設要在陣列 arr 中，尋找「總和不超過 target 的最長連續子陣列長度」：

  1. 初始化兩個指標 left = 0 和 right = 0，以及用於記錄視窗狀態的變數（如 current_sum = 0）與結果 max_len = 0。
  2. 當 right < 陣列長度 時，執行以下步驟：
    • 擴張視窗：將 arr[right] 加入視窗狀態（current_sum += arr[right]）。
    • 檢查條件與收縮視窗：當視窗狀態不符合條件（current_sum > target）時，不斷將 arr[left] 移出視窗（current_sum -= arr[left]），並將 left 往右移 (left += 1)，直到視窗重新符合條件。
    • 更新結果：確認視窗符合條件後，更新目前的最大長度（max_len = max(max_len, right - left + 1)）。
    • 擴張準備：將 right 往右移 (right += 1)。
  3. 走訪完成後，回傳 max_len。

4. 程式碼實作

Python 實作範例 (可變長度視窗)

def longest_subarray_sum_at_most_target(arr, target):
    """
    可變長度滑動視窗：尋找總和 <= target 的最長連續子陣列長度
    """
    left = 0
    current_sum = 0
    max_len = 0
    
    # right 指標負責擴張視窗
    for right in range(len(arr)):
        current_sum += arr[right]  # 將新元素加入視窗
        
        # 若視窗內總和超過 target，left 指標開始收縮視窗
        while current_sum > target and left <= right:
            current_sum -= arr[left]  # 將最左邊的元素移出視窗
            left += 1                 # 縮小視窗範圍
            
        # 此時視窗內的總和必定 <= target，更新最大長度
        max_len = max(max_len, right - left + 1)
        
    return max_len

# 測試區塊
data = [3, 1, 2, 7, 4, 2, 1, 1, 5]
target_value = 8

result = longest_subarray_sum_at_most_target(data, target_value)
print(f"總和不超過 {target_value} 的最長連續子陣列長度為: {result}")

5. 複雜度分析

  • 時間複雜度 (Time Complexity)：
    • $O(N)$。雖然程式碼中有 for 迴圈包著 while 迴圈，但陣列中的每個元素最多只會被 right 指標加入視窗一次，也最多只會被 left 指標移出視窗一次。指標只進不退，因此總操作次數約為 $2N$，複雜度為 $O(N)$。
  • 空間複雜度 (Space Complexity)：
    • $O(1)$。若只計算總和或長度，僅需常數個變數記錄狀態。若題目要求記錄字元出現次數，可能需要 $O(K)$ 的雜湊表 (Hash Table) 空間（$K$ 為字元集大小）。

6. 特性總結與適用時機

  • 關鍵字辨識：當題目出現「連續子陣列 (Contiguous Subarray)」或「子字串 (Substring)」，並且要求尋找「最長 (Longest) / 最短 (Shortest)」或「最大 (Maximum) / 最小 (Minimum)」時，極大機率是滑動視窗題型。
  • APCS 考試應用：
    • 滑動視窗是 APCS 第 3 題 極度頻繁出現的題型。遇到這類題目若使用雙層迴圈暴力解必定會 TLE，必須熟練掌握 left 與 right 指標的維護方式，以及視窗內狀態（如總和、計數器）的更新時機。
